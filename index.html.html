이 정보는 어디서 왔나요?

위치·면수·운영시간·요금·예상 잔여석(예: 34/192면)은 공공데이터포털의 전국주차장정보 표준데이터를 본뜬 샘플 데이터예요. 실제 서비스로 만들려면 공공데이터포털 API 키를 발급받아 연동해야 해요.

지도 핀과 목록의 여유/만차 표시(상태 뱃지)는 센서가 아니라 이용자들이 직접 남긴 제보예요. 제보 후 30분이 지나면 "정보 오래됨"으로, 1시간이 지나면 다시 "정보 없음"으로 흐려져요. 아직 아무도 제보하지 않았을 땐 예상 잔여석 숫자만 참고하세요.

이 20곳은 처음부터 전역을 다 넣지 않고, 유동인구가 많은 곳부터 1차로 선정한 목록이에요. 지금 등급(매우 많음/많음)은 관광지 인지도 등을 참고한 추정치이고, 실제로는 제주 관광빅데이터플랫폼 같은 방문객 통계와 연동할 수 있어요. 이용이 쌓이면 "확장 예정" 지역부터 순차적으로 넓혀갈 계획이에요.
